## Contexto

Proyecto universitario en equipo de 4: el módulo de Contabilidad y Finanzas de Flowy ERP. Cubre el plan de cuentas, los asientos contables manuales y automáticos, los libros contables, los estados financieros y el cierre de gestión.

## El proyecto completo

- API REST en Express organizada en capas: rutas, controladores, servicios, repositorios y modelos.
- MySQL con Sequelize, Redis y un frontend en React.
- Todo el entorno se levanta con Docker Compose y se valida con GitHub Actions.

## Por qué lo destaco

Los libros de Compras y Ventas tocan la misma lógica que veo en mi trabajo con la facturación y las compras de un ERP.
